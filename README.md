# دعوة أنس ويارا

صفحة دعوة عربية ثابتة وجاهزة للنشر. لا تحتاج إلى تثبيت حزم أو إعداد build.

## النشر على Netlify

1. ارفع مجلد المشروع أو اسحب ملف `index.html` إلى Netlify Drop: https://app.netlify.com/drop
2. بعد النشر، افتح رابط الموقع للتأكد من ظهوره.
3. رمز QR داخل الدعوة ينشأ من رابط الموقع المنشور؛ افتح الصفحة بعد النشر واضغط «رمز الدعوة».

## ملاحظات

- التقويم والمشاركة والخريطة ورمز QR مفعّلة.
- خطا Cairo وAmiri يأتيان من Google Fonts، ورمز QR يُحمّل من QR Server عند فتح نافذته.
- لم تُضف صورًا أو موسيقى أو وسيلة هدية لعدم توفر ملفات أو بياناتها.
